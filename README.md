# FB Reel Saver

Chrome extension (Manifest V3) that lists the videos on a Facebook page or profile with **thumbnails and captions**, remembers **which ones you've already downloaded**, and automates the [SaveFrom.net](https://en1.savefrom.net/) flow for you: paste the link, pick **MP4 720p**, download, and name the file after the page and video ID.

> ⚠️ **Experimental.** It depends on the HTML of Facebook and SaveFrom.net, which can change at any time. See [Known limitations](#known-limitations).

## What it does

Doing this by hand looks like: open the page → copy the reel link → open SaveFrom → paste → click Download → wait → pick MP4 720p → click Download again. This extension does all of that from one button.

- **Video list panel** on any Facebook page/profile (button at the bottom-right: `📋 Mga video`)
  - thumbnail preview, caption, video ID
  - status per video: **Hindi pa** (not yet) / **✓ Na-download** (downloaded) with date
  - filter tabs: All / New / Downloaded
  - click a thumbnail to scroll to that post on the page
- **One-click download** per video, or on a reel/video page the button becomes `⬇ Download this video`
- **Auto SaveFrom.net**: fills the link, submits, waits for the result, picks the 720p MP4 (best effort), and starts a real download
- **Clear file names**: `PageName_VideoID_YYYY-MM-DD.mp4`
- **Download tracking**: a video is marked as downloaded only when the file has actually **finished** downloading. You can also mark/unmark manually.
- **Banner on SaveFrom** showing which video is being downloaded, and the tab closes itself when done
- **Debug button** (🐞) that copies a report you can paste into an issue

## Install (from source)

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select this folder (the one that contains `manifest.json`).
4. Open a Facebook page or profile. **Refresh the tab** if it was already open.

> After you reload/update the extension, refresh your Facebook tabs. Old tabs keep a stale copy of the script and will show `Extension context invalidated`.

## Usage

1. Go to a Facebook page, for example `facebook.com/SomePage`.
2. Click **`📋 Mga video`** (bottom-right). Scroll down the page to load more posts; the list updates as you scroll.
3. Click **`⬇ Download`** on a video.
4. A SaveFrom.net tab opens, does the steps automatically, downloads the file, and closes itself.

The button is hidden on non-page areas such as the home feed, Marketplace, Groups and Messages, unless you are on a reel/video page.

## How it works

| Part | File | What it does |
| --- | --- | --- |
| Facebook UI | `facebook.js` | Finds video links on the page (`/reel/…`, `/videos/…`, `/watch/?v=…`), builds the list panel, stores download status |
| Video metadata | `facebook.js` | Reads the thumbnail (`preferred_thumbnail`), caption (`message.text`) and page name from the JSON embedded in the page. If a video isn't in the page data, it fetches that reel page in the background (max 40 per page load, 1.5 s apart, only while the panel is open) |
| SaveFrom automation | `savefrom.js` | Fills `#sf_url`, clicks `#sf_submit`, waits for links in `#sf_result`, chooses the best 720p MP4 link |
| Downloads & state | `background.js` | Opens the SaveFrom tab, starts the download with `chrome.downloads`, watches it until it completes, marks it as downloaded |

Thumbnail URLs from Facebook are signed and expire after a few days, so they are cached only briefly and re-fetched when needed.

## Permissions

| Permission | Why |
| --- | --- |
| `storage` | Remember which videos are downloaded and cache captions/thumbnails locally |
| `downloads` | Start the download and give the file a clear name |
| `https://www.facebook.com/*` | Show the panel and read video info from the page |
| `https://*.savefrom.net/*` | Fill in the form and read the result |

## Privacy

- All data (downloaded list, cached captions/thumbnail URLs) is stored **locally** in your browser with `chrome.storage.local`.
- The extension has no server and sends nothing to the author.
- To download a video, its Facebook link **is sent to SaveFrom.net**, a third-party service. Review their terms and privacy policy.

## Known limitations

- **Depends on site HTML.** Facebook and SaveFrom change their pages often. Captions and thumbnails are best-effort and may be missing on some posts.
- **Quality selection is best-effort.** The SaveFrom result markup is generated by JavaScript; the extension scores links (720p, MP4) and falls back to the default one.
- **Posts that don't link to a reel/video URL** may not appear in the list.
- **"Latest video"** is judged by position on the page, so a pinned post can appear first.
- **Automated background requests** to Facebook (metadata fetch) can look like bot activity. Use it at a normal pace.
- UI text is currently in Filipino/Taglish.

## Troubleshooting

- **`Extension context invalidated`** → refresh the Facebook tab (F5).
- **No thumbnail/caption** → scroll a bit, wait a few seconds, then press 🐞 and attach the copied report to an issue.
- **Nothing downloads** → open DevTools (F12) on the SaveFrom tab and look for messages starting with `[RZ]`.
